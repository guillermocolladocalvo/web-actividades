PROYECTO ACTIVIDADES WEB

Página principal

En esta página web se recopilan todas las actividades realizadas durante el proyecto de implantación y configuración de servicios en red utilizando Ubuntu Server, Apache, FTP, VLANs y OCS Inventory.

Actividad 1

Preparación del entorno, instalación de Ubuntu Server y aplicaciones necesarias.

Actividad 2

Diseño de red, VLANs y configuración de OCS Inventory.

Actividad 3

Montaje de cableado, conectores RJ45 y pruebas con tester.

Actividad 4

Configuración del servidor web Apache y despliegue inicial.

Actividad 5

Configuración del servicio FTP y transferencia de archivos entre cliente y servidor.

Actividad 6

Desarrollo final de la página web utilizando HTML, CSS y GitHub.

Información del proyecto

Proyecto realizado por el grupo ASIR 2026 utilizando Ubuntu Server 24.04, Apache2, Visual Studio Code y GitHub.
