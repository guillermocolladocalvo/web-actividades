Actividad 1 - Preparación del entorno

En esta actividad realizamos la preparación inicial del entorno de trabajo. Instalamos Windows mediante USB booteable, configuramos Ubuntu Server en el Dell Wyse y descargamos las aplicaciones necesarias para el proyecto.

Tareas realizadas

  • Creación de USB booteable Windows 11
  • Instalación Ubuntu Server 24.04
  • Configuración inicial del sistema
  • Instalación de aplicaciones necesarias
  • Preparación del servidor Wyse
